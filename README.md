**Selected work**
- [federated-learning-packet-loss](https://github.com/chai6699/federated-learning-packet-loss) —
  FedAvg simulator characterising how gradient compression and client selection

  policies, common random numbers for paired comparisons, and a changelog of
  defects found auditing my own results.
